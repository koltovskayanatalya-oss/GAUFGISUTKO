# Методика bottom-up расчёта модельной массы ТКО по МНО

## 1. Принцип

Масса рассчитывается сначала для каждого МНО на основании параметров контейнерного хозяйства и графика вывоза, затем суммируется до населённого пункта. Официальная масса НП не распределяется между МНО. Она может использоваться только для проверки и, при обоснованной необходимости, калибровки агрегированных результатов.

В исходной методике указано, что официальные значения доступны для 191 НП из примерно 1642. Источник, период и сопоставимость этих значений необходимо подтвердить до расчёта метрик и калибровки.

## 2. Исходные таблицы

- `mno_raw` — реестр МНО из ФГИС УТКО: ID площадки, координаты, число и объём контейнеров/бункеров по СТКО, РТКО и КГО.
- `pickup_schedules_raw` — графики вывоза из ФГИС УТКО: ID графика, ID МНО или территории, вид графика, периодичность, дни вывоза, поля «Каждые nn дней» и «Через mm дней».
- `mno_np_link` — связь МНО с населённым пунктом.

Одна площадка может иметь несколько записей графика — по разным типам отходов или расписаниям. Их нельзя механически считать одним графиком.

## 3. Годовая частота вывоза

Использовать приоритетную последовательность исходной методики:

1. Если заполнены поля «Каждые nn дней» и/или «Через mm дней», интервал равен сумме заполненных значений, частота — `ROUND(365 / интервал, 0)`.
2. Если периодичность в днях отсутствует, использовать вид графика и его расписание: ежедневно — 365; дни недели/месяца и периодичность — по правилам исходной методики.
3. Для графиков «по заявкам» применять только как модельные допущения: СТКО — 52, РТКО — 24, КГО — 12, иные отходы — 4 вывоза в год.
4. Для «выбранных дат» считать даты и экстраполировать на год; если дат нет, использовать предусмотренную исходной методикой медианную оценку: 24 для СТКО/РТКО и 12 для КГО.
5. Для «вывоз не осуществляется» частота равна 0.
6. Составные записи с `;` разобрать отдельно; пересекающиеся дни не учитывать дважды.
7. Если отдельные поля пусты и применяется подстановка, явно сохранить исходное значение, принятое допущение и флаг импутации. Не считать импутированную частоту фактическим расписанием.

Подробная таблица типовых паттернов из исходной методики (в том числе множители дней недели/месяца, специальные случаи и правила составных записей) сохранена в папке `90_Архив_исходных_редакций` в исходном документе расчёта массы. При фактической обработке применять одну согласованную версию этих правил и сохранять её номер.

Итоговая таблица `schedule_frequency`: `id_mno`, `waste_type`, `frequency_per_year`, `frequency_rule`, `imputation_flag`, `source_schedule_id`.

## 4. Расчёт массы

Для МНО `i` и типа отходов `t`:

\[
M_{i,t}=N_{i,t}\times V_{i,t}\times F_{i,t}\times K_{зап,t}\times \rho_t
\]

где:
- `N` — число контейнеров/бункеров;
- `V` — объём одного контейнера, м³;
- `F` — частота вывоза за год;
- `Kзап` — коэффициент заполнения;
- `ρ` — расчётная плотность, т/м³.

| Тип отходов | Kзап | ρ, т/м³ |
|---|---:|---:|
| СТКО | 0,75 | 0,22 |
| РТКО | 0,75 | 0,22 |
| КГО | 0,60 | 0,15 |

Эти коэффициенты взяты из исходной проектной методики и являются модельными допущениями. Не выдавать их за результаты измерений.

Годовая масса МНО:

\[
M_i=\sum_t M_{i,t}
\]

Годовая масса НП:

\[
M_{NP}=\sum_{i\in NP}M_i
\]

Если отсутствует число/объём контейнеров или невозможно обоснованно определить частоту, МНО получает `insufficient_data`. Не распределять массу НП поровну или пропорционально по неподтверждённым данным.

## 5. Проверка по официальной массе НП

Если источник, период и охват официальной массы подтверждены:
- сравнить официальные и модельные агрегаты;
- рассчитать MAPE, Bias и R² как диагностические показатели (учесть, что MAPE не определяется для нулевых официальных значений);
- изучить крупные расхождения, не исправляя их вручную;
- калибровать только при устойчивом систематическом смещении и сопоставимых данных;
- хранить исходную модельную массу и калиброванную массу раздельно.

## 6. Выходная таблица `mno_mass_calculation`

Минимальные поля: `id_mno`, `id_np`, `waste_type`, `container_count`, `container_volume_m3`, `frequency_per_year`, `fill_coefficient`, `density_t_m3`, `mass_t_year`, `calculation_status`, `imputation_flag`, `source_id`, `method_version`.

## 7. Контроль

Проверить единицы измерения, расчётный период, отсутствие отрицательных значений, аномальные выбросы, наличие флагов импутации и равенство агрегата НП сумме рассчитанных масс МНО (отдельно показывая МНО с недостаточными данными).
