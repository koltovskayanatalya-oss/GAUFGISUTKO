# Каталог слоёв и таблиц этапа 1

Имена ниже — рекомендуемые имена рабочих слоёв и таблиц в GeoPackage/табличных файлах. Это не названия готовых выгрузок ФГИС УТКО. Поля и идентификаторы уточняются по фактической схеме полученных файлов.

## 1. Пространственные слои

| Рабочее имя | Геометрия | Откуда берём | Основные поля / содержание | Использование |
|---|---|---|---|---|
| `region_boundary` | Polygon | ГАУ, ГИС «Земля» | ID, название, дата | Граница анализа |
| `municipality_l1` | Polygon | ГАУ, ГИС «Земля» | ID, название, уровень | Свод по МО 1-го уровня |
| `municipality_l2` | Polygon | ГАУ, ГИС «Земля» | ID, название, родительский ID | Детальные своды |
| `settlements` | Polygon | ГАУ, ГИС «Земля» | ID НП, название, ID МО | Связь МНО и агрегация массы |
| `settlement_centroids` | Point, производный | Центроиды `settlements` | ID НП, метод создания | Резервная привязка, если полигоны недоступны |
| `mno_raw` | Point | ФГИС УТКО / исходный слой QGIS | Исходные атрибуты, координаты, ID | Неизменяемый источник |
| `mno_clean` | Point | Очистка `mno_raw` | ID, координаты, контейнерные атрибуты, флаги качества | Проверенный реестр площадок |
| `mno_demand` | Point | `mno_clean` + `schedule_frequency` + расчёт массы | Масса, тип отходов, частота, статус | Основные точки спроса |
| `mno_clusters` | Point, необязательный | Производный из `mno_demand` | ID кластера, число МНО, сумма массы | Только техническое укрупнение при необходимости |
| `infrastructure_active` | Point | ФГИС УТКО / Экологическое агентство / Заказчик | ID, тип, статус, мощности, дата | Допустимые назначения |
| `infrastructure_inventory` | Point | eco29.ru | ID, тип, статус, источник | Сверка инвентаризации |
| `infrastructure_excluded` | Point | Производный из инвентаризации | Исходный ID, причина исключения | Контроль неиспользуемых объектов |
| `road_edges` | Line | Областной граф Заказчика; OSM через OSMnx | ID ребра, класс, длина, направление, покрытие/скорость/ограничения если есть | Рёбра дорожного графа |
| `road_nodes` | Point | Производный из `road_edges` | ID узла, компонент связности | Узлы графа |
| `snapped_demand` | Point | `mno_demand` + дорожный граф | ID МНО, ID ребра/узла, расстояние привязки, статус | Проверка привязки спроса |
| `snapped_facilities` | Point | `infrastructure_active` + дорожный граф | ID объекта, ID ребра/узла, расстояние привязки | Проверка привязки объектов |
| `selected_routes` | Line | Сетевой расчёт | ID МНО, ID объекта, сценарий, длина | Только выборочная проверка маршрутов |

## 2. Таблицы без геометрии

| Имя таблицы | Источник | Ключевые поля | Назначение |
|---|---|---|---|
| `pickup_schedules_raw` | ФГИС УТКО | ID графика, ID МНО/территории, тип, периодичность, дни, «каждые/через N дней» | Исходные расписания |
| `mno_np_link` | Расчёт | ID МНО, ID НП, метод связи, расстояние, уверенность | Связь МНО–НП |
| `schedule_frequency` | Расчёт | ID МНО, тип отходов, частота/год, правило, флаг импутации | Нормализованная частота |
| `mno_mass_calculation` | Расчёт | Параметры контейнеров, F, Kзап, ρ, масса, статус | Bottom-up расчёт по МНО |
| `np_mass_official` | Имеющаяся таблица проекта; источник уточнить | ID НП, масса, период, источник | Сравнение с моделью |
| `np_mass_model` | Расчёт | ID НП, сумма масс МНО, число МНО, число неполных записей | Агрегация bottom-up |
| `data_quality_register` | Проверки | Набор, проверка, всего, валидно, доля, статус | Паспорт качества |
| `data_issue_log` | Проверки | ID, ошибка, действие, источник исправления | Журнал проблем |
| `od_matrix` | Сетевой расчёт | ID МНО, ID объекта, расстояние, время если есть, достижимость | Сетевые расстояния |
| `scenario_register` | Сценарный расчёт | ID МНО, сценарий, объект, масса, расстояние, W, ΔW, ограничения, статус | Главный реестр |
| `uncertainty_register` | Аналитическая оценка | ID/территория, пробел, влияние, требуемая проверка | Неопределённость |
| `municipality_summary` | Агрегация | ID МО, масса, W базы, ΔW, число МНО и проверок | Сводные результаты |

## 3. Обязательные правила хранения

- Исходные данные не перезаписывать.
- Для каждого слоя/таблицы хранить источник, дату получения, дату актуальности, CRS/EPSG и версию обработки.
- Неизвестные значения хранить как `NULL`, а не 0.
- Официальные, модельные и импутированные значения различать отдельными полями/флагами.
- Исключённые строки сохранять с причиной.
- Кластерный слой, если он нужен, не заменяет исходные МНО.
