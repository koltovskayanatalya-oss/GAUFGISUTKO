Проект научно-исследовательской программы по пространственному моделированию, оценке инфраструктуры и проектированию картографического сервиса обращения с твердыми коммунальными отходами (ТКО) в Архангельской области.

Статус: в разработке
ГИС-инструменты: QGIS, GeoPandas
Анализ данных: Python, OSMnx

## О проекте

Репозиторий содержит методологию, технические планы и отчетные материалы проекта, направленного на переход от разрозненных реестровых данных ФГИС УТКО к обоснованной, основанной на ГИС-анализе, системе поддержки принятия решений. 

Проект позволяет ответить на ключевые вопросы региональных операторов и органов власти:
1. Какие территории и кластеры мест накопления отходов (МНО) создают наибольшую модельную транспортную нагрузку?
2. Где существуют пространственные дисбалансы между объемами образования ТКО и доступностью инфраструктуры?
3. Какие территории могут быть предварительно рассмотрены для размещения новых объектов инфраструктуры?
4. Как сделать результаты сложного пространственного анализа понятными для специалистов без глубоких ГИС-навыков?

## Цели и задачи

- Сценарная оценка логистики: Расчет модельной транспортной работы (тонно-километры) от конкретных МНО до действующих объектов инфраструктуры с использованием реального дорожного графа.
- Модельный расчет массы ТКО: Восстановление данных об объемах образования отходов на уровне отдельных контейнерных площадок (bottom-up approach) на основе параметров контейнерного хозяйства и графиков вывоза.
- Региональная пространственная диагностика: Выявление статистически устойчивых зон дисбаланса спроса и доступности инфраструктуры.
- Предварительная оценка размещения инфраструктуры: Формирование исключающих масок и карт предпочтений (suitability analysis) для отбора перспективных площадок.
- UX/UI проектирование: Создание и валидация прототипа картографического веб-приложения для удобной интерпретации данных и фиксации управленческих решений.

## Ключевые особенности методологии

- Bottom-up моделирование: Масса ТКО рассчитывается для каждого МНО по формуле: M = N_контейнеров * V_объема * F_частоты_вывоза * K_заполнения * rho_плотности, с последующей агрегацией до уровня населенного пункта.
- Сетевой анализ (Network Analysis): Маршруты строятся не по прямой, а по реальному дорожному графу (OpenStreetMap) с процедурой привязки (snapping) точек МНО и объектов инфраструктуры к дорожной сети.
- Сценарное сравнение: Оценка базового сценария (S0) против альтернативных (S1, S2, S3) для выявления потенциала оптимизации транспортной работы (Delta W) с учетом ограничений (остаточная мощность, сезонность дорог, тип объекта).
- Контроль качества данных: Строгий паспорт качества данных с фиксацией доли валидных координат, дубликатов и записей, требующих ручной верификации.

## Ограничения и область применения

Важно: Результаты данного моделирования являются сценарными и оценочными. Они не заменяют собой территориальную схему обращения с отходами, договорную работу, инженерные изыскания, финансово-экономическое обоснование, экологическую оценку или юридическую экспертизу.  
Цель проекта – сократить неопределенность и предоставить адресный список территорий и сценариев, требующих дополнительной проверочной работы.
