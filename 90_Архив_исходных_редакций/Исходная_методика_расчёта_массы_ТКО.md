# Методика модельного расчёта массы образования твёрдых коммунальных отходов (ТКО) на уровне мест накопления

## 1. Методологическое обоснование

В связи с отсутствием данных о фактической массе образования ТКО для подавляющего большинства населённых пунктов (НП) Архангельской области (официальные данные доступны лишь для 191 из ~1642 НП), в работе применён метод модельной оценки «снизу вверх» (_bottom-up approach_).

Модельная масса рассчитывается для каждого места накопления отходов (МНО) на основе фактических параметров контейнерного хозяйства и графика вывоза, после чего агрегируется до уровня НП путём суммирования. Данный подход научно обоснован, так как фактическая логистическая схема регионального оператора эмпирически адаптирована под реальный объём образования отходов, и параметры контейнерного хозяйства (количество, объём, частота вывоза) содержат достаточную информацию для восстановления модельного спроса.

## 2. Исходные данные

Для расчёта используются два взаимосвязанных реестра:

### 2.1. Реестр мест накопления отходов (МНО)

Содержит 15 350 объектов с дифференцированными данными по трём типам отходов для каждой площадки:

- **СТКО** (совместное накопление ТКО): количество контейнеров (NСТКОNСТКО​), объём контейнера (VСТКОVСТКО​)
- **РТКО** (раздельный сбор ТКО): количество контейнеров (NРТКОNРТКО​), объём контейнера (VРТКОVРТКО​)
- **КГО** (крупногабаритные отходы): количество контейнеров/бункеров (NКГОNКГО​), объём контейнера (VКГОVКГО​)

### 2.2. Реестр графиков вывоза

Содержит ~25 000 записей, определяющих периодичность обслуживания. Каждая запись описывается полями:

1. Вид графика вывоза отходов
2. Периодичность вывоза
3. Дни вывоза отходов
4. Периодичность в рамках месяца
5. Каждые nn дней (приоритетное поле)
6. Через mm дней (приоритетное поле)

Расхождение количества записей (15 350 МНО против ~25 000 графиков) обусловлено тем, что на одной площадке могут присутствовать контейнеры для разных типов отходов с различными графиками вывоза. Также встречаются **составные записи**, где для одной площадки указаны несколько графиков, разделённых точкой с запятой `;` (например, разные дни для разных недель месяца).

## 3. Расчёт годовой частоты вывоза (FF)

Годовая частота вывоза (FF, вывозов/год) рассчитывается дифференцированно по строгой приоритетной логике:

### 3.1. Приоритет 1: Периодичность в днях

Если заполнено поле «Каждые nn дней» или «Через mm дней», расчёт выполняется по формуле:

F=ROUND(365n+m,0)F=ROUND(n+m365​,0)

где:

- nn — значение поля «Каждые nn дней» (при пустом n=0n=0)
- mm — значение поля «Через mm дней» (при пустом m=0m=0)

Интерпретация: интервал между вывозами составляет (n+m)(n+m) дней.

### 3.2. Приоритет 2: Вид графика и импутация пропусков

При пустых полях периодичности в днях применяется логика по виду графика. Для обеспечения полноты расчёта к пустым значениям применена процедура импутации на основе нормативных дефолтов:

#### 3.2.1. Ежедневно

F=365F=365

#### 3.2.2. Периодически по дням недели

F=Nдней×KпериодF=Nдней​×Kпериод​

где:

- NднейNдней​ — количество уникальных дней в поле «Дни вывоза отходов» (разделитель — запятая или точка с запятой)
- KпериодKпериод​ — множитель периодичности

**Импутация:** если поле «Дни вывоза» пусто, принимается «Понедельник» (Nдней=1Nдней​=1). Если поле «Периодичность в рамк. месяца» пусто, принимается «Каждую неделю» (Kпериод=52Kпериод​=52).

**Множители:**

- Каждую неделю → Kпериод=52Kпериод​=52
- Каждый первый → Kпериод=12Kпериод​=12
- Каждый второй → Kпериод=12Kпериод​=12
- Каждый третий → Kпериод=12Kпериод​=12
- Каждый четвёртый → Kпериод=12Kпериод​=12
- Каждый последний → Kпериод=12Kпериод​=12

**Важное правило:** если в поле «Периодичность в рамках месяца» указано несколько значений (например, «Каждый первый,Каждый второй,Каждый третий,Каждый четвёртый»), множители **суммируются**. Например: «Каждый первый,Каждый второй» → Kпериод=12+12=24Kпериод​=12+12=24.

**Правило вложения:** если указано «Каждую неделю», это уже включает все недели месяца, поэтому дополнительные множители («Каждый первый» и т.д.) **не суммируются**, берётся максимум (Kпериод=52Kпериод​=52).

#### 3.2.3. Периодически по дням месяца

F=Nдней×12F=Nдней​×12

где NднейNдней​ — количество чисел в поле «Периодичность вывоза» или «Дни вывоза отходов» (разделитель — запятая).

**Импутация:** если поле с днями пусто, принимается «1» (Nдней=1Nдней​=1). Если указано «Каждый последний день месяца», F=12F=12.

**Специальные случаи:**

- «Будние дни» → F=5×52=260F=5×52=260
- «Четные дни» → F=15×12=180F=15×12=180

#### 3.2.4. По заявкам

Применяется дифференцированная оценка на основе морфологии отходов:

- **СТКО:** F=52F=52 (санитарный минимум 1 раз в неделю)
- **РТКО:** F=24F=24 (2 раза в месяц, сухие фракции накапливаются медленнее)
- **КГО:** F=12F=12 (1 раз в месяц, эпизодическое накопление)
- **Иные отходы:** F=4F=4 (ежеквартально, минимизация риска завышения)

#### 3.2.5. Выбранные даты

- **При наличии перечня дат:** F=ROUND(Nдат×365/Tпериода_в_днях,0)F=ROUND(Nдат​×365/Tпериода_в_днях​,0), где NдатNдат​ рассчитывается как `(ДЛСТР(ячейки) - ДЛСТР(ПОДСТАВИТЬ(ячейки; "."; ""))) / 2` (подсчёт точек в датах формата ДД.ММ.ГГГГ).
- **При отсутствии перечня дат (пустое поле):** применяется медианная оценка по аналогам: F=24F=24 для СТКО/РТКО, F=12F=12 для КГО.

#### 3.2.6. Вывоз не осуществляется

F=0F=0

### 3.3. Обработка составных записей

Если в записи графика присутствует разделитель `;` (точка с запятой), это означает несколько отдельных графиков для одной площадки. В этом случае:

1. Каждый график рассчитывается отдельно по правилам выше.
2. Результаты **суммируются**.
3. Если дни пересекаются (например, «Понедельник,Вторник,Среда,Четверг,Пятница,Суббота;Понедельник,Вторник,Четверг,Пятница»), считаются только **уникальные дни** (в данном случае 6 дней × 52 = 312).

## 4. Расчёт модельной массы ТКО для каждого МНО

Для каждого типа отходов (t∈{СТКО,РТКО,КГО}t∈{СТКО,РТКО,КГО}) на каждой площадке (kk) рассчитывается годовая масса по формуле:

Mk,t=Nk,t×Vk,t×Fk,t×Kзап,t×ρtMk,t​=Nk,t​×Vk,t​×Fk,t​×Kзап,t​×ρt​

где:

- Nk,tNk,t​ — количество контейнеров типа tt на площадке kk
- Vk,tVk,t​ — объём одного контейнера типа tt, м³
- Fk,tFk,t​ — годовая частота вывоза типа tt, вывозов/год
- Kзап,tKзап,t​ — коэффициент заполнения контейнера
- ρtρt​ — плотность ТКО, т/м³

**Дифференцированные коэффициенты:**

|Тип отходов|KзапKзап​|ρρ, т/м³|Обоснование|
|---|---|---|---|
|СТКО|0.75|0.22|Стандартная плотность непрессованного ТКО|
|РТКО|0.75|0.22|Сухие фракции, аналогичная плотность|
|КГО|0.60|0.15|Крупногабаритные отходы менее плотные, заполнение неравномерное|

**Итоговая масса площадки:**

Mk=∑tMk,t=Mk,СТКО+Mk,РТКО+Mk,КГОMk​=∑t​Mk,t​=Mk,СТКО​+Mk,РТКО​+Mk,КГО​

## 5. Агрегация до уровня населённого пункта

Модельная масса населённого пункта (ii) определяется как сумма масс всех входящих в него МНО:

miмодель=∑k∈KiMkmiмодель​=∑k∈Ki​​Mk​

где KiKi​ — множество МНО, отнесённых к населённому пункту ii.

Таким образом, расчётная масса ТКО получается автоматически для всех населённых пунктов, где имеется хотя бы одна площадка с валидными данными.

- **Случай А** (miмодель≫miофицmiмодель​≫miофиц​): возможное наличие неучтённого сезонного населения, несанкционированного ввоза отходов из соседних территорий или заниженный норматив накопления.

## 7. Ограничения модели

1. Модель оценивает потенциал образования ТКО на основе параметров контейнерного хозяйства, а не фактические объёмы вывезенных отходов.
2. Коэффициенты заполнения и плотности приняты как типовые значения; фактические значения могут отличаться в зависимости от морфологического состава отходов и сезонности.
3. Импутация пропущенных значений вносит неопределённость в оценку частоты вывоза; соответствующие МНО помечены флагом «требует верификации».
4. Модель не учитывает сезонные колебания образования ТКО (например, увеличение объёма в дачный сезон).
5. Расчётная масса не является основанием для изменения маршрутов или закрепления территорий без дополнительной проверки остаточных мощностей объектов и сезонной доступности дорог.
