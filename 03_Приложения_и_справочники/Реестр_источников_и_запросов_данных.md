# Реестр источников и запросов данных

В таблице отделены источники, уже названные в исходных материалах проекта, от данных, которые ещё нужно запросить или проверить. Конкретные даты, номера выгрузок, URL, EPSG и владельцы заполняются после получения файлов; не подставлять их предположительно.

| Данные | Что уже указано в проекте | Что запросить/проверить | Если не получено |
|---|---|---|---|
| Граница области, МО, НП | ГАУ / ГИС «Земля» | Актуальная выгрузка, ID, дата, EPSG | Использовать имеющуюся версию с датой и оговоркой |
| МНО | ФГИС УТКО; имеющийся подготовленный слой QGIS | Свежий реестр, координаты, ID, контейнеры по СТКО/РТКО/КГО | Неполные МНО маркировать; не рассчитывать массу без обязательных параметров |
| Графики вывоза | ФГИС УТКО | Поля расписаний, ID МНО/территории, раздельность по типам отходов | Неизвестную частоту помечать; импутации явно фиксировать |
| Действующие объекты | ФГИС УТКО / Экологическое агентство; в исходном описании — 46 объектов | Статус, тип, координаты, мощность, остаточная вместимость, дата | Неизвестную мощность хранить как NULL и помечать «требует проверки» |
| Полный перечень объектов | eco29.ru; в исходном описании — 332 объекта на начало ноября 2026 | Актуальный файл и причины отличий от реестра действующих | Только сверка; не назначать все объекты автоматически |
| Официальная масса НП | Таблица проекта; исходная методика указывает 191 НП | Первичный источник, период, единицы, охват | Не выполнять калибровку без подтверждения сопоставимости |
| Дорожная сеть | Областной граф Заказчика; OpenStreetMap через OSMnx | Дата, классы дорог, ограничения, мосты, сезонность | OSM — приближённая сеть; неизвестные ограничения помечать |
| Население | В исходниках отмечено, что полного набора может не быть | Росстат/региональная статистика с ID НП/МО и годом | Не считать показатели на человека |
| ООПТ | Нужны для этапа 2 при применимости | Официальные федеральные/региональные границы и режимы | Не объявлять территорию допустимой без критического слоя |
| Водоохранные зоны | Нужны для этапа 2 при применимости | Официальные границы и режимы | Статус «недостаточно данных» |
| ЗОУИТ/санитарные зоны | Нужны для этапа 2 при применимости | ЕГРН/НСПД и сведения профильных органов | Не строить юридические исключения по неофициальным подложкам |
| Земли и ВРИ | Нужны для этапа 2 при применимости | ЕГРН/НСПД/земельные органы | Не делать вывод о правовой допустимости |
| Застройка и соцобъекты | Нужны для этапа 2 | Муниципальные/региональные официальные слои; OSM только справочно | Не использовать OSM как единственное доказательство нормативных расстояний |
| Рельеф | Возможный фактор предпочтения | Региональная DEM или открытая DEM с разрешением и датой | Исключить фактор из расчёта, а не подставлять значения |
| Геология, гидрогеология, подтопление, мерзлота, почвы | Названы в исходных материалах как возможные тематические данные | Профильные государственные фонды и органы | Указать неопределённость; отсутствие слоя не означает отсутствие риска |
| Нормативные требования | Нужны для выбранного типа объекта | Актуальные федеральные/региональные НПА и дата проверки | Не строить итоговую маску до проверки требований |
| Экспертные веса | Согласуются при MCDA | Заказчик/эксперты, основания и дата | Не выдавать веса за нормативные значения |

## Правило источника

Для каждого полученного набора записать: наименование источника/организации, файл или реквизиты выгрузки, дату получения, дату актуальности, владельца, формат, EPSG (если есть), ограничения использования. Если точные реквизиты в исходных документах отсутствуют, указать «уточнить при получении».
