# PyQGIS scripts — контроль качества bottom-up расчёта

Запускать из **QGIS → Python Console**, по одному скрипту за раз. Все скрипты только читают данные: не редактируют объекты, не создают и не удаляют слои, не сохраняют изменения.

Порядок:
1. `01_structure_capacity_audit.py` — структура, ключи, количество контейнеров и `Capacity_m3`.
2. `02_schedule_frequency_audit.py` — частоты, статусы и периоды действия.
3. `03_interval_calendar_2026_audit.py` — календарная диагностика 10 интервальных графиков по гипотезе n дней вывоза + m дней перерыва.
4. `04_mass_formula_audit.py` — сверка массы с формулой; запускать только после фиксации корректной частоты за 2026 год.
5. `05_schedule_value_profile.py` — профиль значений расписаний для восстановления парсера.

Оговорки:
- Частота >52 не считается ошибкой автоматически.
- Правила 12/52 и географические исключения не применяются скриптами.
- Скрипт 03 проверяет гипотезу цикла, а не утверждённый парсер для всех расписаний.
- Скрипт 04 использует коэффициенты последнего описанного сценария: СТКО/РТКО 0,75 × 0,22; КГО 0,40 × 0,15.
