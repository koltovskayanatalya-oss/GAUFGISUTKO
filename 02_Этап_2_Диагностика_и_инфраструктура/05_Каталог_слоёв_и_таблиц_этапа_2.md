# Каталог слоёв и таблиц этапа 2

Второй этап использует результаты этапа 1 и добавляет только те внешние слои, которые действительно нужны для выбранного типа объекта. Не требуется собирать все перечисленные тематические данные, если они не влияют на применимые критерии или отсутствуют в пригодном масштабе.

## 1. Повторно используемые слои и таблицы этапа 1

| Набор | Геометрия/тип | Источник | Использование |
|---|---|---|---|
| `region_boundary`, `municipality_l1/l2`, `settlements` | Полигоны | ГАУ, ГИС «Земля» | Пространственные единицы анализа |
| `mno_clean`, `mno_demand` | Точки | ФГИС УТКО + расчёт этапа 1 | Пространственное распределение спроса |
| `np_mass_model`, `municipality_summary` | Таблицы | Расчёт этапа 1 | Сводные показатели |
| `infrastructure_active` | Точки + таблица | ФГИС УТКО / Экологическое агентство | Доступность и обеспеченность |
| `road_edges`, `road_nodes` | Линии/узлы | Областной граф / OSMnx | Сетевая доступность |
| `od_matrix` | Таблица | Расчёт этапа 1 | Расстояния и достижимость |
| `scenario_register` | Таблица | Расчёт этапа 1 | W, ΔW, ограничения |
| `data_quality_register`, `uncertainty_register` | Таблицы | Этап 1 | Учет неопределённости |

## 2. Внешние данные для диагностики и MCDA

| Слой/таблица | Геометрия | Откуда получать | Обязательность и правило |
|---|---|---|---|
| `population_by_settlement` — численность населения | Таблица с ID НП/МО | Росстат или региональный орган статистики | Необязательный; удельные показатели считать только при сопоставимом периоде и географии |
| ООПТ | Полигоны | Официальные федеральные/региональные реестры ООПТ, уполномоченный орган | Для исключений, если режим применим к выбранному типу объекта |
| Водоохранные зоны и прибрежные защитные полосы | Полигоны/линии | Официальные сведения водного реестра, Росреестр/НСПД, уполномоченные органы | Использовать подтверждённые границы и правовой режим |
| ЗОУИТ и санитарные ограничения | Полигоны/зоны | ЕГРН/НСПД, официальные сведения органов власти и владельцев объектов | Проверять вид зоны, дату и правовой режим |
| Категории земель и ВРИ | Полигоны/таблица | ЕГРН/НСПД, органы земельных отношений | Не определять правовой статус по одной подложке |
| Жилая застройка | Полигоны/точки | Официальные муниципальные данные; OSM только вспомогательно | Для нормативных расстояний нужен официальный/проверенный источник |
| Социальные объекты | Точки | Муниципальные/региональные реестры; OSM для предварительного обзора | Дата и полнота обязательны к указанию |
| Цифровая модель рельефа | Растр | Региональные данные или открытые DEM, например Copernicus DEM/SRTM | Необязательный фактор предпочтения; не заменяет инженерную съёмку |
| Геология и грунты | Полигоны/точки/отчёты | Государственные геологические фонды, региональные материалы, профильные органы | Только при подходящем масштабе и актуальности |
| Гидрогеология и подтопление | Полигоны/растры | Официальные профильные материалы, региональные органы, данные МЧС по зонам риска | При отсутствии указывать неопределённость, а не отсутствие риска |
| Мерзлота и почвы | Полигоны/растры | Государственные тематические фонды и официальные научно-картографические источники | Использовать только если критерий применим и масштаб достаточен |
| Дороги, мосты и сезонные ограничения | Линии/точки/таблица | Областной граф Заказчика, региональный дорожный орган, муниципалитеты; OSM вспомогательно | Подтверждать грузовые/сезонные ограничения |
| Нормативные требования | Таблица/документы | Действующие федеральные и региональные НПА, официальные публикации | Проверить актуальность и применимость именно к выбранному объекту |
| Экспертные веса | Таблица | Согласование с Заказчиком/экспертами | Зафиксировать основания и дату; не выдавать за нормативные значения |

## 3. Производные слои и таблицы

| Имя | Тип | Содержание / источник |
|---|---|---|
| `regional_indicators` | Таблица | Спрос, доступность, W/ΔW, инфраструктура и качество данных; расчёт из этапа 1 |
| `spatial_weights` | Матрица/таблица | Соседство НП/МО; формируется из границ ГАУ, только если применима пространственная статистика |
| `moran_results` | Таблица | I, ожидаемое значение, p-value, число наблюдений и вариант матрицы; условный результат |
| `lisa_results` | Таблица + слой | Локальный класс и значимость; только если применим анализ LISA |
| `territory_typology` | Таблица + слой | Тип A–E, показатели, основание и уверенность |
| `object_requirements` | Таблица | Тип объекта, норматив, источник, дата проверки и применимость |
| `exclusion_mask` | Polygon/Raster | Исключено/не исключено и причина |
| `preference_factors` | Raster/Polygon | Исходные и нормализованные факторы предпочтения |
| `mcda_preference` | Raster/Polygon | Относительный балл предпочтения, не юридическая пригодность |
| `uncertainty_map` | Raster/Polygon | Пробелы/неопределённость данных |
| `sensitivity_results` | Таблица + слой | Сравнение базового и альтернативного набора весов |
| `candidate_areas` | Polygon | Предварительные зоны-кандидаты и их характеристики |

## 4. Минимальные требования к метаданным

Для каждого слоя фиксировать: название, геометрию, источник/владельца, дату получения, дату актуальности, масштаб или разрешение, CRS/EPSG, применённую обработку, ограничения и статус подтверждения. Если официальный слой не получен, не подменять его случайной интернет-картой для юридических исключений.
