# Проект НИР по пространственной оценке логистики и инфраструктуры ТКО Архангельской области

## Как устроена работа

Проект разделён на **два последовательных договорных этапа**. Сначала выполняется логистический расчёт на уровне МНО. Только после проверки его результатов начинается региональная диагностика и предварительная оценка инфраструктуры.

### Этап 1. «Сценарная логистика ТКО»

Данные ГАУ/ГИС «Земля» + ФГИС УТКО + сведения об объектах + дорожный граф → очистка и связи МНО/НП/графики → bottom-up масса по каждому МНО → дорожный граф и сетевые расстояния → S0 и доступные альтернативы → W/ΔW → пять карт и реестр проверочных действий.

### Этап 2. «Региональная пространственная диагностика и оценка инфраструктуры ТКО»

Проверенные результаты этапа 1 → региональные показатели → карты спроса/доступности/качества → Moran’s I/LISA при применимости → типология A–E → выбор одного типа объекта → официальные ограничения → маска исключений и карта предпочтений → неопределённость и проверка устойчивости → зоны-кандидаты → макеты Figma.

## Структура архива

- `00_Общее` — структура, сводный план и принятые решения.
- `01_Этап_1_Сценарная_логистика` — технический план, bottom-up методика, каталог слоёв и таблиц, исходный паспорт качества данных.
- `02_Этап_2_Диагностика_и_инфраструктура` — технический план, методика диагностики/типологии, методика MCDA, задание Figma и каталог слоёв/таблиц.
- `03_Приложения_и_справочники` — ТЗ первого этапа, реестр источников, проверка согласованности и подробный перечень карт с содержанием, слоями/таблицами и ограничениями интерпретации.
- `90_Архив_исходных_редакций` — исходные документы из переданного архива без смыслового редактирования. Они нужны для истории и сверки; при противоречиях применять актуальные документы разделов 00–03.

## Важные правила

- Масса рассчитывается bottom-up по МНО; официальная масса НП не распределяется между площадками.
- Неизвестные значения сохраняются как NULL, а не как 0.
- Список объектов назначения формируется только из подтверждённых действующих объектов подходящего типа.
- Время движения рассчитывается только при наличии скоростей.
- Необязательные операции (кластеризация, Moran’s I/LISA при слабых данных, MCDA при отсутствии нормативных слоёв) не форсируются.
- Во втором этапе интерфейс только прорисовывается в Figma; возможен кликабельный демонстрационный прототип. Рабочее приложение, программирование и UX-валидация не входят.

## Основные инструменты

QGIS — проверка и оформление пространственных слоёв; Python/pandas/GeoPandas — подготовка таблиц и расчёты; OSMnx/NetworkX — дорожный граф и сетевые расстояния; Figma — только визуальные макеты.

## Как читать документы

1. Начать с этого README и `Сводный_план_НИР_2_этапа.md`.
2. Для первого этапа использовать технический план, каталог слоёв и методику bottom-up.
3. Для второго этапа — технический план, каталоги слоёв, методики диагностики/MCDA и задание Figma.
4. Для подготовки карт использовать `03_Приложения_и_справочники/Перечень_карт_и_картографических_материалов.md`.
5. Исходные документы в `90_Архив_исходных_редакций` не использовать как актуальную инструкцию там, где они противоречат обновлённым решениям.
