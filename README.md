# Сценарная оценка транспортной работы и вариантов направления потоков ТКО в Архангельской области

Проект НИР по пространственному анализу обращения с твёрдыми коммунальными отходами (ТКО) в Архангельской области. Цель — подготовить воспроизводимую ГИС-основу для оценки логистики ТКО и последующей региональной пространственной диагностики.

**Текущий договорной этап:** этап 1 — «Сценарная логистика ТКО».  
**Текущая задача:** верификация исходных данных и bottom-up расчёта массы до построения дорожного графа.  
**Контрольная дата статуса:** 27.11.2026.

## С чего начать

Откройте [состояние проекта и план завершения этапа 1](00_Общее/Состояние_проекта_и_план_завершения_этапа_1.md). В нём зафиксированы текущий статус, уже выполненные проверки, открытые вопросы, последовательность продолжения и иерархия документов.

## Договорная структура проекта

Проект состоит из двух договорных этапов. Сейчас выполняется только первый.

### Этап 1. Сценарная логистика ТКО

Подготовка и проверка исходных данных → bottom-up расчёт массы по МНО → дорожный граф и OD-матрица → базовый и доступные альтернативные сценарии → транспортная работа → карты и технический отчёт.

**Текущий статус:** подготовка данных и расчёт массы ещё не закрыты. Полная календарная проверка частот вывоза не завершена. Дорожный граф не строился.

### Этап 2. Региональная пространственная диагностика и оценка инфраструктуры ТКО

Региональные показатели спроса и доступности → Moran’s I/LISA при применимости → типология территорий → предварительная оценка размещения одного выбранного типа объекта → визуальные макеты Figma.

**Статус:** последующий договорной этап; в текущей работе не выполняется.

## Основные рабочие правила

- Единица расчёта — строка «МНО — поток»; потоки СТКО, РТКО и КГО не смешивать.
- `Capacity_m3` — суммарная ёмкость потока на МНО; не умножать её повторно на количество контейнеров.
- `_Итоговое количество вывозов` — расчётное поле, не первичный факт. Частоту требуется независимо восстановить по календарю 2026 года и сроку действия графика.
- Не применять автоматически прежние правила «12 вывозов» и ограничение 52.
- Неизвестные значения не заменять нулями; ноль допустим только при подтверждённом отсутствии вывоза.
- Не восстанавливать искусственно отсутствующие территории и не выдавать промежуточную массу за итоговую.
- К дорожному графу переходить после закрытия верификации данных и подготовки технического отчёта.
